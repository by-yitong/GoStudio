TOOLCHAIN

真·Linux 工具链，
跑在 Android 里。

GoStudio 通过 proot + Alpine rootfs 在设备上构建出一套完整的 Go 工具链运行环境。golang、gopls 全部内置，开箱即用。

  • proot 用户态隔离，无需 root 权限
  • Alpine rootfs，golang / gopls 开箱内置
  • 构建、调试、语言服务同环境运行

$ go version

$ go build ./...

FEATURES

一个 IDE 该有的样子，
一个都不少。

LSP

gopls 语言智能

官方语言服务完整接入，Sora 编辑器里的每一次按键都有回应。

  • 代码补全
  • 参数提示
  • 符号高亮
  • 实时诊断
  • 悬浮提示
  • 跳转定义
  • 格式化
  • 重命名

EDITOR

Sora 编辑器

标签页、文件树、全局搜索、快捷符号栏，为触屏优化的代码编辑体验。

GIT

随时克隆项目

从 GitHub / Gitee / GitLab 克隆 Go 项目，支持 HTTPS 与 SSH、Token、私钥和 GitHub OAuth 设备码登录。

RUN

AndLua 式运行

XML 布局 + Go 逻辑，构建后直接在宿主界面运行，无需打包 APK。

LOGS

输出面板

构建与工具链日志统一收口，问题一眼可见。

BUILD

项目配置

Go 版本、构建目标、构建参数与并行任务数，按项目自定义。

TEMPLATES

从一个模板开始，
而不是一个空文件夹。

  • Hello World
  • HTTP Server
  • CLI Tool
  • Web API
  • Gin
  • GORM
  • Cobra
  • Echo

每个模板自动生成 go.mod 与入口文件，保存 go.mod 即可触发模块刷新。

PLUGINS

数据包插件，
安全地扩展能力。

GoStudio 的插件不执行代码。一个 manifest 加能力目录，就是全部结构——当前支持 AI 技能扩展，模板与主题正在路上。
