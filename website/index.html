手机上的 Go IDE。
工具链，一条不少。

1.0 克隆· 2.0 编辑· 3.0 构建· 4.0 运行

1.0 · 克隆

把仓库放进手机，或者从模板开始。

从 GitHub、Gitee、GitLab 克隆 Go 项目——HTTPS、SSH、Token、GitHub OAuth 设备码都可以登录，克隆完成自动导入最近项目。

从零开始同样就绪：Hello World、HTTP 服务器、CLI、Web API，以及 Gin、GORM、Cobra、Echo 框架模板，创建即生成 go.mod 与入口文件。

2.0 · 编辑

gopls 接住每一次按键。

官方语言服务 gopls 完整接入：补全、参数提示、符号高亮、实时诊断、悬浮提示、跳转定义、格式化。

Sora 编辑器提供标签页、文件树、全局搜索与快捷符号栏——一套为触屏优化的编辑体验。

3.0 · 构建

构建发生在手机上，不在云端。

proot + Alpine rootfs 在设备上构建出完整的 Go 工具链环境——golang 与 gopls 开箱内置，无需 root 权限，也不依赖云端。

构建与工具链日志统一收进输出面板；Go 版本、构建目标、构建参数、并行任务数，按项目自定义。

4.0 · 运行

写完即运行，不必先打包 APK。

AndLua 式 App 运行：layout.xml 声明界面，main.go 编写逻辑。点击「运行」，GoStudio 先编译 Go 二进制，再在宿主界面内直接渲染布局、启动逻辑——改一行，再跑一次。

需要分发时，同样的布局与二进制也可以注入独立壳应用，打包成 APK。

插件是数据，不是代码。

一个 manifest.json 加一个能力目录，就是插件的全部结构——不执行任何代码。当前支持 AI 技能（skills/）扩展，templates/ 与 themes/ 已预留。

在插件市场一键安装，或把目录打成 ZIP 本地导入；装完即用，可随时禁用或卸载。
